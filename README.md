# 《欢迎来到月球》离线翻牌辅助器 (Welcome to the Moon - Flip Assistant)

> 💡 **关于作者与这个项目**：
> 我是一个热爱桌游的普通玩家，没有多少编程基础。这个项目源于一次线下聚会：官方小程序无法访问，实体牌翻起来既繁琐又容易把“数字面/图标面”弄混，单人亚星模式的计分更是让人猪脑过载。
> 
> 抱着试一试的心态，我借助了 AI 编程工具（DeepSeek Harness），通过不断提出需求、测试、修改 UI，最终诞生了这个工具。**代码由 AI 生成，但我参与了所有架构设计、数据录入、痛点挖掘和无数次的体验打磨。** 
> 
> 我希望把它分享给同样热爱这款游戏的你们。在这个 AI 时代，即使你不懂代码，只要有想法，也能创造属于自己的工具。祝你们在月球殖民愉快！

## ✨ 核心特性
- **🛡️ 完全离线**：单文件或多文件本地直接运行，无网络焦虑，不依赖服务器。
- **👥 多人模式**：支持关卡选择、任务卡计分（首发高分/后续低分）、步骤回退。
- **🤖 单人战役 (ASTRO)**：完美整合亚星 NPC 逻辑。
  - 选择8个关卡和8个亚星对手；  
  - 动态根据选择的星舰卡牌配对数字与行动；
  - 自动计算加权分与奖励分；
  - 查看亚星效果和奖励条件；
  - 使用亚星奖励移除卡牌；
  - 抽牌到第二轮结束回合，自动进入结算页面。 
- **📱 沉浸式暗黑 UI**：专为平板和桌面聚会设计，远距离也能看清大字。

## 目录结构说明

**离线版工具**
Solo为亚星单人战役模式，Filp Assistant为经典多人联机版。tablet为便携版（直接下载带tablet后缀的文件，独立可玩），支持离线使用，适合在移动设备（最好是平板）上体验；


**可配置数据版工具（依赖关联文件）**
1. index.html 经典联机模式：
- data：关卡数据，唯一外部 JS 配置
- action image：含6 张行动图标
- mission image：含49张任务资源

2. solo.html单人战役模式：
除了上面的data、action image、mission image文件以外，还额外需要文件
- solo image：含亚星奖励图标

PS:index.html 不是 solo.html 的依赖
